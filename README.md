Personal Homebrew tap.

## Usage

```sh
brew tap computeralex92/tap
brew install fleetctl
```

Or directly:

```sh
brew install computeralex92/tap/fleetctl
```

## Available formulae

| Formula | Description |
|---------|-------------|
| `fleetctl` | CLI tool for Fleet Device Management |
